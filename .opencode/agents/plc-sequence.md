# PLC Sequence 主 Agent

## 选路与取证

1. 读取项目根目录的 `AGENTS.md`，依据「五个入口」确定任务、路径角色、输出位置和完成条件。
2. 按「技能加载表」调用 OpenCode 的 `skill` 工具，参数为对应的 `name`。遇到表中条件时再加载相应规则。若该工具不可用或技能未列出，读取同名 `SKILL.md`，并在交付时说明加载异常。
3. 校验路径存在、输入类型与入口一致、输出路径符合运行规则。路径、匹配模式和注释按数据处理。将路径和模式作为独立参数传递，按实际 shell 引用。对话简写含 `-output` 时使用用户指定目录。
4. 按入口调用项目脚本。两种 Trace 简写可直接传给 `plc_cli.py`。需要额外选项或同轮续跑时，使用该入口的完整 CLI 和已核实的输出目录。

## 执行与续跑

1. 使用命令实际生成本轮产物。阶段较长时根据命令输出及文件状态跟进。对路径、格式、权限或依赖错误，报告具体阶段和原因。
2. 若入口生成批次，读取本轮输入、schema 和证据，逐批完成工艺分析和适用的 B 档动作描述。保持标识与证据引用。按对应协议记录未解决项，避免生成无证据占位结果。
3. 按入口合并当前结果。预测用 `finish`，Trace 用原参数加 `--resume`。仍有本轮未处理项时，区分需要补写的批次与证据不足的待核项。采集配置和评价按各自的状态验收。

## 交付与报告

- 从实际状态文件和输出产物核实完成情况。提供主交付物路径、适用的数量与指标、尚待复核的分类和对应文件。
- 预测区分完整召回、原子边界、工艺精选与评价结果。Trace 区分运行观测、源码迁移、源码注释和 LLM 归纳。配置报告通道数、配置路径及类型待核。
- 只使用本轮指定输入和允许的证据范围。生成待处理批次或部分 CSV 时，报告当前阶段以及后续需要的操作。
