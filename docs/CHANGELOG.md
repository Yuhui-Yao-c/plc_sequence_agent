# 变更记录

## 10.2.0 — 采集配置支持多模式并集（2026-11-11）

- 入口二支持 `源码 模式1 [模式2 ...] --trace-setup [-output 输出根目录]`，完整 CLI 可重复指定 `--pattern`。每个模式独立编译，混用完整名称、通配和 `re:` 正则；一次扫描取并集，重叠变量去重，保留自然排序。
- 保留单模式、`--regex`、大小写匹配、类型核验及输出子目录规则。状态文件新增 `patterns`，原 `pattern` 在单模式时仍为字符串，多模式时为 `null`。
- 多模式不替代功能块实例解析或缺失类型声明。入口一的 Trace 解析、状态对聚合和描述协议保持原实现；不同命令共享步号的上下文问题仍需独立适配。
- 56 项回归测试通过，覆盖模式并集、重叠去重、混合正则与通配、多维下标、大小写、独立模式校验、两种 CLI 形式及输出子目录。三个真实工序原有 90、154、128 个通道的单模式配置逐字节一致，OpenCode 主 Agent 与技能加载通过。
- 配对机 XML 的三个模式合并得到 46 个显式变量，与单独匹配的并集一致，无重复；34 个变量缺少成员类型声明，仍如实标记 `needs_review`，此数量不代表完整实例化后的全部步序。

## 10.1.0 — 双入口简化版与版本标识统一（2026-11-11）

- 将当前双入口、包目录化的简化版统一标为 `10.1.0`，区分历史单入口简化版 `10.0.x`。此前 `VERSION=9.28.0` 和清单中的 `version=9.28` 是沿用值，未反映后续修改。
- 根目录 `VERSION` 为唯一程序版本来源。新增 `python plc_cli.py --version`，源码准备清单及两个入口的状态文件使用同一版本。Trace v4 证据协议编号保持不变。
- 原子投影审计中的旧 `version=9.13` 同样改为程序版本。52 项回归测试通过，包含外部工作目录版本查询、两个入口的版本标识及版本文件的指纹覆盖。
- [VERSIONING.md](VERSIONING.md) 记录九个远端分支的用途、核查基线、维护状态及升级约定。此次仅更新 `trace-only`，保留其它分支及其提交。
