## 18.4.0 — 按加工与交接边界复核内部子步（2026-11-26）

入口二先确定工位要计时的加工或交接动作，再核对移除某个地址后会失去哪项工步的起点或终点。主步在设备动作开始后可能继续执行其他指令，直到进入等待步才开始计量剩余等待。长期并行工作的物料通道则要分别检查每件工件的交接时刻。

当同一父流程启动私有子流程、期间继续执行自身动作、最后读取终值放行时，程序还核对子步中间值的所有可见读者，以及放行后父步是否接管子步操作的各个执行器。满足这些条件的内部动作在备选表保留完整地址。判断记录保留父子实例、实际写入点及交还的控制输出。已有诊断需求时，可用独立 `--reference` 指定完整实例地址。范围结果同时记录复核提交的 `use`、最终生效的 `effective_use` 和决定是否入表的 `admission`。

只汇总成组到位信号、随后由上层统一放行的通道，以及仅启动多个可自行反复作业的子流程后便停驻的写点，分别记录汇合条件和实际启动关系。仅以这些汇合或启动关系申报生产计时时，程序将地址转回待核。其他运行模式有独立生产边界的地址，按其生产写点判断。

配对机的 `EM03_循环区域.fbEM510.iChildStep` 和 `EM03_循环区域.fbEM600.iChildStep` 都是实际存在的功能块私有地址。在 `iCmdNo=2` 的生产段，各自的 `stEM510.CmdSta.iCmdStep`、`stEM600.CmdSta.iCmdStep` 从 `100` 启动对应实例，继续推进到 `130`，读到子步 `1000` 后转入 `140`。子步 `10 → 20 → 1000` 控制的四个定位气缸都由父步接管。工位等待的开始与结束在父步上可见，气缸内部的两段定位时间可另行诊断。
